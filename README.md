# FinTerminal

类理杏仁（Lixinger）的金融数据查询与分析终端。支持**股票 / 指数 / 基金**的行情查询、历史走势、估值分析、财务派生、行业对比、条件选股与自选列表。

行情与 K 线来自公开接口；个股估值使用已披露财报、真实股本与前复权价格复算。首页财务指标使用所列报告期的披露数据；行业与选股页的 ROE 为 PB ÷ PE 推导的估算值，单独标注。行情接口失败时使用带快照标识的历史数据。

**技术选型与理由**

| 层 | 选型 | 理由 |
|---|---|---|
| 框架 | Next.js 15 App Router | 行情接口有 CORS 限制且返回 GBK，必须有服务端代理；单进程同时承担 SSR 与 API，部署最省事 |
| 语言 | TypeScript strict | 多数据源字段错位是这类项目的头号 bug 来源，类型能挡住大半 |
| 样式 | Tailwind CSS 3 | 卡片/表格密集的金融界面，原子类迭代最快 |
| 图表 | ECharts 5（按需注册） | K 线 + 缩放 + markLine 组合能力强，按需引入控制体积 |
| 存储 | 访客本地缓存 / 可选 PostgreSQL | 行情实时抓取不落库；账号个人数据按用户隔离 |
| 缓存 | 进程内 TTL Map | 单实例足够；换多实例时替换成 Redis 即可（接口不变） |

### A 股估值口径

个股估值采用真实披露的归母净利润、归母普通股净资产与股本变动史。利润 TTM 按“今年累计 + 上年全年 − 上年同期累计”拼接。每个交易日使用真实公告次日起可得的最新报告；利润亏损、数据缺失与无法识别公告日时保留缺失状态，不继续套用旧盈利，也不自动生成估算曲线。

价格曲线采用腾讯**前复权日线**。EPS、每股净资产同时乘以前复权价／不复权价因子，再计算 PE、PB，因此复权处理不会改变估值比率。长历史按最多 640 条分页抓取，价格口径必须显式匹配。真实股数按交易日变动，避免把每股面值默认为 1 元。行情接口 PE/PB 作为参考单独显示，不覆盖财报复算值。

分位基于所选区间有效交易日。股息率默认采用**已公告方案延续法的预期股息率**：从方案公告次日起，按最近一个报告年度周期的年报、中报或季报方案估计未来一年的税前每股股息，再除以当日不复权收盘价。新周期方案替换旧期，不跨两年叠加同一笔年报分红；旧方案超过公告周年三个月未更新则停止外推；已除息的特别分红不重复预计。零分红与金额未确定分开处理，数据不可得时预期值为缺失，不冒充静态值。默认数值、历史曲线及分位使用相同预期口径。

卡片后附**（静 …%）**：延用原股息率的过去十二个月已实施税前分红口径；送转后的每股分红按实际股数调整，与同日不复权股价匹配。预期方案由东方财富 `RPT_SHAREBONUS_DET` 获取，静态已实施分红来自新浪。预期是分红水平延续的估计，并非确定的未来分红；接口没有完整的方案修订历史，历史金额可能包含后续修订，不能当作严格时点回测数据。真实报告日期由新浪历史公告列表获取；财务金额仍可能是数据源后续重述版本。显示实际样本数及起止日期。

### 港股与财务分析

港股使用东方财富 HKF10 指标和三表；保留数据源的币种标识，金额从元换算到万，展示时折算到亿。报告类型按公司财年确定，阿里巴巴等非自然年公司不按 12 月末筛选年报；三表明细按照 `STD_REPORT_DATE` 对齐，防止将上一期余额挂到新一期。报表分页完整拉取，A 股和港股配置分别保存。

港股当前 PE/PB 使用数据源声明为 HKD 的 EPS_TTM/BPS 与港元行情计算，亏损时 PE 为缺失值；行情 PE 仅作参考。股息率以最新年度每股股息 HKD 除以当前股价计算，标为原口径。HKF10 没有可核验的历史公告日期和历史分红快照，暂不展示历史估值曲线/分位，不能用报告期末冒充披露日，也不能把当前股息率回填成历史曲线。新上市股票没有 K 线时仍可查询当前估值和财报。

财务趋势节点数据默认显示，任一图表按钮统一切换全部图表。合并报表的自选视图名称为「自定义财报」。利息保障倍数使用 `(利润总额 + 费用化利息费用) / 费用化利息费用`，两项金额均来自东方财富同一期利润表；这是不含资本化利息的口径，分母缺失或非正时不计算，禁止使用净财务费用代替。默认自定义指标名称去掉「自算」，保留已有配置 ID。

财务报表表头为近两年报告期提供原文入口（`?view=table` 可直接打开表格）。`/api/financial-reports?code=300498` 按公司查询巨潮定期报告目录，只缓存标题、披露日期、报告期和 PDF 地址一小时，不保存 PDF 文件。匹配季度、中期和年度全文，排除摘要、英文版、业绩公告与母公司代披露的子公司报告，同期优先最新全文及修订版。原文在新标签页打开，不改变同季度高亮；未准确匹配的报告不显示链接，目录失败时保留财报并提供重试。港股仅匹配可确认的完整报告；非自然年公司须有明确报告期，不用自然年推断。

## 三、主要页面与模块

| 路由 | 类型 | 内容 |
|---|---|---|
| `/` | Client | **研究工作台**：按自选分组查看公司动态，最近公司笔记与每日心得同屏展示；支持公告摘要、原文跳转、读取已有笔记与新建笔记。公告按每批 15 家 A 股加载，港股公告暂未接入；桌面适配剩余窗口高度，手机按区块排列。 |

| `/stock/[code]/finance` | Server + Client | **指标趋势**：模块内全部图表纵向排列，左侧吸附指标导航，点击定位、拖动排序；每图展示当前值与区间统计。支持双公司对比、年报/中报/季报、5/10 年切换，保留模块配置与自定义公式。移动端导航横向滚动。 |
| `/stock/[code]/finance` | Client | **合并报表**：保留单公司模式；在指标、完整利润表、资产负债表和现金流量表之间切换；2/3/5/10 年、报告类型、搜索、空行切换、指标配置和 CSV 导出；金额统一亿元，首行/首列吸附，表内滚动。保留「累积」「单季」增长率行。 |
| `/watchlist` | Client | **自选公司**：完整基本面比较表，支持分组、名称/代码筛选、自定义表头、排序、批量导入与逐项移除；PE/PB 行情口径与所列报告期的财报指标分别展示，最新报告期缺值时不沿用旧值。原有指数/基金关注项保留在折叠的「其他关注标的」中。 |
| `/industry` | Client | **行业研究**：申万 2021 三级分类，名称/代码筛选、PE/PB 中位数、估算 ROE、市值及排序；保留亏损股。短期涨跌和换手率移出主表，分类口径默认折叠。 |
| `/screener` | Client | 行业、PE/PB、估算 ROE 下限和市值筛选；预设、排序、自选操作和 CSV 导出。 |
| `/index/[code]` | Server + Client | 指数点位、历史走势、区间表现与估值。 |
| `/fund`、`/fund/[code]` | Server + Client | 基金/ETF 列表与历史走势。 |
| `/health` | Server | 数据源可用性、延迟与降级状态。 |

访客自选、研究笔记和指标配置仍保存在当前浏览器。已加入手机号登录界面、签名会话、按账号独立缓存和 PostgreSQL 个人数据同步接口；短信服务默认未启用，需要 WorkBuddy 接入真实供应商并配置会话密钥与数据库，详见 [WORKBUDDY_AUTH.md](WORKBUDDY_AUTH.md)。账号菜单支持主动合并本机原有记录与同步冲突处理，AI API Key 不上传数据库。全站采用紧凑导航与小边距的全宽布局，宽屏上导航、标志和搜索同排；财务页标题与视图切换同排，报表高度根据实际剩余窗口空间调整。保留灰白底色、蓝色操作按钮，并适配电脑和手机。

分组支持批量导入同花顺导出的 TXT / CSV / TSV / XLS / XLSX 和剪贴板代码，兼容 UTF-8、GBK、UTF-16、Excel 前导零格式和多工作表。导入前核对股票身份、显示重复和失败行；仅跳过目标组内已有股票，其他分组的股票可重复加入并保留原归属。支持原子新建分组与导入，一次最多 2000 行、每个文件最多 5 MB。文件仅在浏览器解析，行情核对只发送股票代码。大量自选按 100 只分批拉取行情，避免单请求数量上限。

分组标签可拖动排序，股票可通过拖动、上下移动按钮或 Alt + 方向键调整顺序；全部自选和各分组分别保存股票顺序。多选分组、批量加入和组间移动均保留不相关分组的归属，移出最后一个分组后进入未分组；全部自选中删除则清除该股票的全部归属。股票列表为单行，悬停或键盘聚焦名称查看代码、市场、行业和所属分组；缺失的行业资料按悬停需要加载。自定义表头可选择及排列估值、财务与行情列，表头支持升降排序，缺失值始终置后，选择手动顺序恢复原顺序。表头配置与自选排序沿用按账号隔离的本地存储和个人数据同步。

**API**（`src/app/api/`）：`quote` `kline` `minute` `search` `valuation` `financial` `finance-fields` `finance-compare` `peers` `screen` `market` `industry` `sw-industry` `health` `ai-analyze`
