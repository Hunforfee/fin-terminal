# FinTerminal

类理杏仁（Lixinger）的金融数据查询与分析终端。支持**股票 / 指数 / 基金**的行情查询、历史走势、估值分析、财务派生、行业对比、条件选股与自选列表。

全部行情与 K 线来自公开接口**实时抓取**，不落库、不写死价格；估值与 ROE 通过严格恒等式从真实行情派生；上游全挂时有真实历史快照兜底。

**技术选型与理由**

| 层 | 选型 | 理由 |
|---|---|---|
| 框架 | Next.js 15 App Router | 行情接口有 CORS 限制且返回 GBK，必须有服务端代理；单进程同时承担 SSR 与 API，部署最省事 |
| 语言 | TypeScript strict | 多数据源字段错位是这类项目的头号 bug 来源，类型能挡住大半 |
| 样式 | Tailwind CSS 3 | 卡片/表格密集的金融界面，原子类迭代最快 |
| 图表 | ECharts 5（按需注册） | K 线 + 缩放 + markLine 组合能力强，按需引入控制体积 |
| 存储 | 无数据库 | 行情实时抓取不落库；自选放 localStorage，零运维 |
| 缓存 | 进程内 TTL Map | 单实例足够；换多实例时替换成 Redis 即可（接口不变） |

| 同花顺 iFinD | MCP 网关 | ❌ 未注册 | 网关返回 `17008`，工具数为 0 |

### 关键设计：不编造数据

缺少合规财务源时，本项目只做**数学上严格成立**的推导：

```
净利润(TTM) = 总市值 ÷ PE
净资产      = 总市值 ÷ PB
ROE         = 净利润 ÷ 净资产 = PB ÷ PE      ← 恒等式
总股本      = 总市值 ÷ 股价
```

这四项与行情估值精度等价，属于「真实派生」。实测贵州茅台：市值 16613.58 亿、PE 20.40、PB 6.61 → 净利润 814.4 亿、ROE 32.4%，与实际财报吻合。

**历史 PE 分位**需要历史 EPS 序列，公开接口拿不到，因此采用「当前 TTM EPS + 由 PE(静)/PE(动) 反解的盈利增速」复合回溯，并在页面上**显式标注为估算口径**，提示不可用于精确回测。

**接入 iFinD 后**：配置 `IFIND_BASE_URL` / `IFIND_TOKEN`，`src/lib/datasource/ifind.ts` 的 `fetchFinancial()` 返回 `provenance: 'fetched'` 的真实三表，上层自动切换——**业务代码零改动**。

## 三、主要页面与模块

## 七、已知边界

- **历史 PE 分位为估算口径**：无历史 EPS 序列，用「当前 TTM EPS + 反解增速」回溯。页面已标注，不建议用于精确回测。
- **财务报表为新浪披露口径**：`/stock/[code]/finance` 的 21 项指标取自新浪财务指引页（原始披露值，非三表原始数据），适合看趋势与横向对比；若需审计级三表，可接入 iFinD（`ifind.ts` 已预留插槽）。
- **个股历史估值（`/api/valuation`，真实三大报表口径）**：PE-TTM = 不复权收盘价 ÷ EPS(TTM)；EPS(TTM) = 利润表「归属于母公司所有者的净利润」TTM ÷ **该报告期期末总股本**（资产负债表「实收资本（或股本）」÷ 面值还原，送转/增发不会放大历史 PE）；TTM 按**四个单季**滚动：Q1 = 今年Q1 + 上年年报 − **上年Q1**（不是 − 上年Q3），中报 = 今年中报 + 上年年报 − 上年中报，三季报 = 今年三季报 + 上年年报 − 上年三季报，年报 = 年报本身；PB = 不复权价 ÷ 归母净资产每股值。生效口径二选一：`method=disclosure`（默认，披露后即纳入，近似「报告期 + 典型滞后 28/58/28/95 天」，理杏仁公司估值口径）或 `method=cutoff`（法定截止日次日统一切换，中证/国证指数口径；响应同时返回另一种口径作 `alt` 叠加对比）。图表支持点击打参考线；分位/分位值/均值按区间内全部交易日计算（与周频复算会有差异）。已对账：茅台 2021 顶 PE≈73、当前 20.4（10Y 分位 ~10%），五粮液/招行/工行/平安银行均落在合理区间。
- **选股池为行业龙头样本**（约 125 只），非全市场 5000+ 只——扩展需接入全量股票列表接口（东财 `clist` 在本环境被封，换成自有列表即可）。
- **东财搜索响应格式不稳定**：已在 `eastmoney.ts` 做容错，失败时由腾讯联想 + 本地池兜底。
- **自选存 localStorage**：未做账号体系；需要跨设备同步时把 `WatchlistProvider` 的读写换成 `/api/watchlist` 即可。
