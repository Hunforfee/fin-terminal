# 数据口径与回归检查

核查日期：2026-10-20。代码工作区基于 fbf8f69，包含此前仅本地的选股请求范围优化；本轮不提交或推送远端。

## 核查范围

- 数据流：腾讯/新浪行情与K线，A股筛选财报，A股真实财报估值，港股主要指标和三表，股息率、财务公式与AI输入。
- 实际接口抽样：贵州茅台、平安银行、宁德时代、腾讯控股、阿里巴巴。
- 自动测试覆盖：TTM拼接、归母与合并利润、公告日、亏损/缺失区间、分红送转、港股币种和每股单位等；这不是逐家公司公告原文审计。

## 已修复

1. 内置资产负债率、有息负债率、现金/有息债与自由现金流公式停止默认缺失填零。明确披露的零仍参与计算，真正缺失显示空值；用户自定义公式主动选择的填零选项不变。
2. 存货/应收周转率标明期末余额口径，避免和平均余额周转率混用；累计值不擅自年化。
3. 港股列表、单只行情、行业表和详情使用统一财务口径PE/PB；原始行情PE保留为 marketPe 对照，缺失财务分母不拿原行情PE冒充复算值。
4. 港股三表停止根据行情柜台CURRENCY自动标成HKD。三表缺少可核验记账币种时标记“原币未核实”；主要指标每股字段标注CNY，不能混作三表单位。图表、表格和CSV保留字段币种提示。
5. 港股毛利率不再冒充主营业务利润率；现金流/净利润不得用归母利润替代合并净利润，缺少同口径分母时留空。
6. 动态/静态PE比值不再冒充净利润同比。PB/PE派生ROE不作为披露的加权平均ROE。
7. AI输入移除“平台核验过”的无依据承诺，保留来源、时间、币种、估算、过期、预期股息率及数据源警告；缺失不填零。
8. A股估值返回的净资产根据同一期财务每股净资产和股本恢复，不再混用当前行情市值和历史点PB反推。
9. K线三/五年范围按真实日期请求，允许分页超过640根；展示实际起止日期、样本数量、来源及复权方式。各市场都禁止用原始价格冒充复权数据；港股默认请求不复权。
10. 港股K线/报价/分时统一为百股成交量，保留小数；分时柱图使用增量而不是累计成交量，避免重复累计。
11. 港股行情回退到历史快照时，不将旧价格与最新财报/分红拼成当前估值，PE/PB与当前股息率保留缺失。
12. 行情数值解析不把空白或布尔值当零/一；拒绝代码身份错配和非请求证券。港股财务拒绝未来报告期，当前财务快照拒绝无效日期。

## 实际接口验证记录

- 2025年茅台归母净利润：新浪万元精度恢复为82,320,067,100元；东方财富为82,320,067,101.68元，差1.68元，与万元字段的展示舍入精度相符。二者属于聚合数据源交叉核对，不代表独立发行人原文复核。
- 腾讯抽样现价410.4港元时，统一口径列表与详情PE均为13.982、PB均为2.853，财年静态股息率均为1.29%；原始腾讯行情PE为14.99，独立保留而不混入统一口径。该组是抽样时点结果，不应当作持续实时价格或投资结论。
- 茅台、平安银行、宁德时代的筛选主要指标与利润表按同一报告期对齐；经营现金流元转亿元只换算一次。银行现金流比率较高不能直接解释为优于非金融公司，跨行业比较应结合业务模式。
- 港股腾讯K线原始成交量为股，分时平均价按金额/股数核对，已统一内部量纲为百股；分时和日K不同更新时间产生的成交量差异不强制覆盖为相等。

- 茅台五年前复权日线实取1,212根，覆盖2021-10-20至2026-10-20，确认五年范围不再止于640根。

## 仍有边界

- 没有对全部公司、全部报告期逐项阅读原始公告。研究稿的内部draft状态和既有核验任务不改变。
- 腾讯、东方财富、新浪可能存在延迟、修订、复权差异、舍入和字段变更。两家接口一致也不等于原始披露必然无误。
- 港股三表原币仍需发行人原文逐家确认；未知币种不猜测、不按HKD转换，不据此做跨币种金额比较。
- A股分红方案历史可能含后续修订；港股缺少可验证历史公告日期时不提供历史估值曲线/分位。当前历史数据不代表严格时点回测数据。
- 自动化测试主要验证解析、计算、降级和展示契约，不证明数据供应商的每个原始值都准确。

口径参考：[证监会净资产收益率与每股收益披露规则](https://www.csrc.gov.cn/csrc/c101864/c1024649/content.shtml)。
