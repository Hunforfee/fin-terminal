# 本轮体检与同步交接

## 修复内容

- 与远端 `74343fd` 合并，保留腾讯第三镜像、WAF 重试、分页间隔和前端重试；分页最终失败仍标记不完整，前端保留来源、实际区间和存储时间说明。
- 有息负债率原来是五个资产负债表科目相加，任一未填值就导致整期为空；科目在当前字段目录中缺失还会使前端无法生成请求依赖。本轮改为请求明确的 `RPT_F10_FINANCE_MAINFINADATA.INTEREST_DEBT_RATIO`，预设 ID 不变，既有页面配置继续生效。
- 有息负债率的值已是百分数，禁止再乘 100。证券、CNY 币种、报告期、披露日期、重复冲突及数值合法性均检查；真实零保留，缺失不当零。字段目录增加同名指标，可直接使用，也可继续使用原预设。
- 新口径是供应商的有息负债率，不能声称与旧五项借款加总完全相同。含金融子公司的合并报表和银行、保险公司尤需区分。页面来源改为东方财富，悬停说明保留此差异。
- 利息费用解析统一使用严格数值解析，空白或布尔值不能变成零。
- 无数据说明改为“暂无可用数据”，避免把来源故障、口径不支持等情况都断言为公司未披露。
- ECharts 升级为 6.1.0；按 Apache 官方 v5 兼容主题保留旧外观。主题直接注册到模块化实例，避免 UMD 主题注册到另一实例。兼容主题复制保留 Apache 许可说明。
- PostCSS 固定 8.5.31，包括 Next 的嵌套依赖，避免要求用户为此迁移整套 Next 主版本。

- 全站 325 项测试通过；生产构建、类型和页面生成检查通过。依赖升级后再次运行回归和构建，以最终日志为准。
- `node scripts/audit-financial-health.mjs` 抽查十家公司，共 591 个报告期，586 个非空有息负债率。原始诊断保存于忽略的 `data/market-audit/financial-health.json`，不提交运行数据。
