# 自选股按分组：直接从网站接口补齐五年

> 当前操作已统一为十年补齐，手动更新入口已移除，入口和缓存规则以 [十年补齐与页面展示缓存](market-display-performance.md) 为准。下文保留历史交接记录。

这是当前默认部署方案，取代 QMT 文件初始化。无需下载、上传或导入任何 QMT ZIP，也无需同步用户电脑上的数据库。已有合法行情继续复用，不清库；原 QMT 导入工具只保留为历史可选工具。

## WorkBuddy 部署步骤

1. 拉取包含本文的最新代码，安装依赖并构建网站。沿用已经建好的 PostgreSQL；保留账号、笔记、自选和研究内容，不重建或覆盖个人表。
2. 网站运行环境配置 `MARKET_DATABASE_URL`（原 `DATABASE_URL` 可继续用于账号库），`MARKET_UPDATE_WORKER_ENABLED=1`，私密的 `MARKET_UPDATE_WORKER_TOKEN`（至少32字符），`APP_ORIGIN=https://实际域名`，以及 `MARKET_CLOSE_UPDATE_ENABLED=1`。凭证只放平台私密配置，不提交 Git。
3. 单独运行并监管 `npm run market:worker`，为 worker 配置相同 token 和 `MARKET_UPDATE_ORIGIN=https://实际域名`。发布网页不会自动启动这个进程。部署平台需允许单阶段最长300秒请求；服务停止后已保存的队列可继续。
4. 初始化前不要设置 `MARKET_READ_MODE=database`；生产禁止 `MARKET_UPDATE_LOCAL_PREVIEW=1`。先允许后台采集和原有混合读取，防止空库时全站缺数据。
5. 用户登录、同步自选清单后，在「自选公司」选择分组再点击「补齐5年」，只提交**当前已同步分组**的公司，不按搜索结果缩小范围，也不会自动扩展到其他分组。用户可逐组提交；相同股票跨组复用已存数据。选择「全部自选」时才提交全部。「更新数据」同样针对当前分组；未初始化的公司会自动先执行完整初始化。
6. 查看进度、失败原因及覆盖记录。完成验收后才开启 `MARKET_READ_MODE=database` 并重启网页服务；即时行情和证券搜索仍可联网。不能把「任务已提交」或「已有部分日线」当作全量补齐成功。

## 采集与校验

- 各公司串行、各阶段有请求预算和间隔。全局队列合并同股任务，限流时暂停，关闭浏览器不影响任务。一次点击可以处理当前自选清单范围，不会抓全市场。
- 直接从网站原有来源读取原价、前复权、三表、财务指标、股本、已实施分红、方案及真实披露日。额外保存接口提供的真实上市日期；新股只能从上市后展示，不伪造上市前五年数据。
- 腾讯或新浪不可用时增加独立的东财行情备用源；明确传入原价/前复权/后复权，核对响应证券，绝不将原价冒充复权价。东财记录由所有页面共用，不另存每个页面一份。
- 公告接口可能提前列出明日的计划日期。未来日期及无效日历日期不会作为已披露事实入库；保留同一响应中其他合法的历史日期，不因一条未来计划阻断全部历史。
- 单阶段失败记录在任务中，继续保存后续独立数据。最后的数据库只读检查确认价格范围、财报基础输入和估值覆盖；不全则记录 `partial` 和缺项，任务失败后可重试。重试从最早失败阶段继续，不只重复最终检查。
- `market-coverage:v1:<symbol>:5` 保存实际起止、来源、`missingInputs`、`gaps`、状态及检查时间。`ready` 是程序完整性校验，不等于人工逐份公告审计。
- 港股采集行情、已支持的财报和当前估值输入；缺少可核验历史披露日/股息快照时，仍不生成历史估值分位。页面及覆盖记录必须保留此能力限制，不将其当作虚构的历史数据。

## 后续维护

登记账号自选后，后台每天北京时间16:30执行收盘更新、次日06:30补偿；更新范围为全部已登记自选（跨分组合并、按代码去重），不再要求先有覆盖记录，删除自选即停止更新。平日收盘场走轻量模式（仅当日价格增量 + 最新财报/分红 + 库内完整性校验），周日06:30补偿场跑一次完整 recent 复核。任务提交时固定本次阶段方案，过程中覆盖状态改变不会导致阶段错位。已初始化公司走近期更新，不每天重做全部历史三表。

前台默认五年，后台最多保留十年并滚动清理。所有页面共享证券级原始输入。股息率与估值继续依赖实际价格、币种、股本、财报和分红证据，缺少依据时留空，不靠假零或推算填齐。

## 验收

先从空的隔离市场库测试普通A股、新上市公司和港股，再验证当前分组提交范围、相同股票合并、前复权备用源、未来公告过滤、失败续跑及收盘更新。检查重启后队列仍在，网页接口读到同一服务器市场库。行情数据、运行报告和私人清单不提交 Git。

2026-10-21 本地验收：377 项回归通过；浏览器只提交所选分组，未发送其他组股票。小商品城与腾讯控股分别从完全空的隔离市场库完成14阶段真实接口采集，无QMT输入；A股五年估值覆盖检查通过，港股保留历史估值分位不可用的限制。临时移除港股一份必需年报现金流表，检查会记录 `partial`，恢复后重新通过。生产库和部署环境仍须按上文单独验收。
