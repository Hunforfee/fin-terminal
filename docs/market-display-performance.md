# 十年补齐与页面展示缓存

## 操作入口

- 自选公司：选择分组 →「管理」→「补齐10年」。进度、停止、失败项重试也在管理菜单内；菜单关闭后仍轮询完成状态。
- 个股首页：雪球前的下载图标。首次点击提交本股票的十年补齐；执行中点击图标查看进度、停止。按钮有名称、状态和键盘焦点。
- 移除手动「更新数据」。公开提交只支持十年补齐；旧 `five-year` 请求兼容升级为十年。`daily/recent` 仅由自动调度使用，16:30 与周日 06:30 的调度规则保留。

## 十年采集

- 不复权和前复权行情各请求最多 3000 条，起点为北京时间当前日往前十个日历年；新股以已核实上市日期为起点。
- A 股按年补三表和财务指标，额外保留起点之前的报告与披露证据，支持起点处的 TTM。财务输入保留两年计算缓冲，行情和展示仍限制十年。
- 估值输入使用 `statements-v3:<code>:11` 与 `disclosures-v3:<code>:12`；短窗口可复用更广输入。港股分别准备五年、十年 PE/PB 来源样本。
- 覆盖记录写 `market-coverage:v1:<symbol>:10`。旧五年就绪记录不代表十年就绪；未结束的旧五年任务撤销旧租约，从新计划首阶段重新开始，已有输入复用。
- 完整性检查实际检查十年行情与估值输入。后台在本地数据库范围内预热五年、十年走势，校验不使用旧结果掩盖输入缺失。

## 估值走势图

- `valuation-result:v1:<symbol>:<years>:<method>` 保存完整曲线、统计和计算口径。算法版本、证券、区间、披露方法隔离。
- 财报、披露日期、股本、分红、原价/前复权价格及港股估值来源实际变更时更新证券级输入版本；API 写入、批量导入、命令行导入和清理删除均经过存储适配器。重复写相同内容或价格查询时间变化不触发曲线失效。
- 同版本、同日、未到24小时的结果直接读取。版本变化/跨日/到期时先显示上次成功结果，Next `after` 后台重算；页面最多轮询四次，失败仍保留旧曲线及其日期。
- 冷启动并发共享计算、跨进程使用同库租约。计算过程中输入变化会再算一次；仍不稳定则不覆盖旧结果。空曲线、快照结果不作为成功缓存保存。
- 港股当前 PE/PB/股息率继续按当前行情计算；历史样本与当前卡片口径保持分开。A 股当前估值沿用最近收盘日口径。
- 数据源/数据库故障不会生成虚构样本。API返回生成时间与是否后台刷新，图表继续标注实际样本截至日期。

## 自选列表

- 浏览器按账号保存上次列表、四项财务、股息率和扣非PE快照，最多复用七天，仅保留当前自选中的记录。该展示缓存不进入个人云同步，不影响个人自选/笔记内容。
- 返回页面先展示已保存记录，再更新行情和指标。保留行情自身时间及财报报告期；缓存保存时间不表示数据截至时间。
- 以当前可见页、当前分组为优先顺序；财务、股息率、扣非PE每批四只，最多两条请求并发。翻页后未完成队列即时提高新可见股票的优先级；离页或切换账号会取消旧请求。
- 服务端股息率结果按证券保存（A股15分钟、港股15秒），扣非PE按15秒保存；输入变更失效。过期先返回标注为旧值的结果，再后台刷新。零值有效，缺失不填零；无法生成新值时保留旧值和生成日期。
- 列表页指标提示可查看生成时间，财务指标显示采用的报告期。完整性缺口、来源限流等仍走原有队列，不在打开列表时启动十年采集。

该改造不修改研究稿、生产数据，不存储PDF文件。首次没有可用结果仍需要真实取数计算，提速主要体现在重复打开和后台已完成采集的股票。
