# 统一市场数据层与十年保留

本轮已经本地验证，并按用户授权准备同步 Git；尚未连接或清理生产数据库。公司解析迁库由另一项工作进行；本轮不修改解析、个人账号、自选分组或笔记表。

## 读取与共享

- 实时行情按证券保存最新原始快照，不保存报价流水。单股、批量、自选与行业入口复用同一记录，批量仅抓缺口；港股派生 PB/股息在原始报价之后计算。开盘时用当前交易时段有效期重新判断，盘前或午休长缓存不能延续至交易时段。
- A 股三表按证券、表类型、年份保存解析后的全部科目，财务目录、自定义字段和估值分母共享。财务指标按证券、年份共享，选择不同字段或比较组合不重新抓同一来源页。保留原币种和单位，不持久化整页 HTML。
- 港股主要指标复用证券级来源记录，三表按证券、表类型、真实报告期保存，批量只补缺少或过期的报告期，不按不同界面组合另存一套。
- 有息负债率、真实利息费用、扣非利润使用各自明确口径的来源输入，列表与图表读取统一入口。最终 PE/PB/股息率仍由当前价格和可用来源计算，不长期存为事实。
- 分红、股本、公告日期、自选指标及选股财报继续复用已有规范记录。完整财务图表去掉组合级的一小时结果缓存，避免掩盖底层输入更新。
- 公告全文、研报和公司简介不作为本轮行情长期库的扩容对象，继续按需读取和原有短缓存；已有深度解析备份不受本轮保留策略影响。

## 防重与故障

同进程相同财务输入合并 Promise。部署 PostgreSQL 后，页面与后台共享基于 CAS 的短租约，不在抓取期间占用数据库连接。K 线按证券、周期和复权方式协调；报价按证券协调，锁按稳定顺序获取；港股三表按证券和表类型协调，选股财报共享更新租约。

租约每 20 秒续期，90 秒未续期可接管，等待有上限。写入仍检查原记录摘要，旧请求不能覆盖并发产生的新版本。数据库不可用或无法核验的结果不伪装为已入库，旧数据的降级标记继续保留。文件适配器仅用于本地单进程预览；跨服务器实例的协调依赖真实 PostgreSQL。

## 保留与清理

上限为滚动十个日历年，按中国时区日期计算，闰日取对应月份有效末日。不是永远保留固定十个年份，也不是到期清空整家公司。

- K 线、财报、分红和日期映射写入时裁掉十年前的数据；读取已有输入同样裁剪，防止旧库存继续展示过期范围。
- 股本保留十年边界上的明确 `baseline: true` 期初状态，用于边界后的估值计算；不保留十年前逐条变动事件，不把基准状态当实际发生的新事件。
- 边界最初部分若缺少完整 TTM/同比计算依据，结果留空，不改报告日期、不猜测金额。未来报告期不能作为已披露历史保存；已公告分红方案仍按其过去报告期和公告口径处理。
- 只保存最新实时快照。报价、最新财务和列表记录连续 30 天未获取则可清理；有效期到期只意味着需要刷新，不等于历史事实必须删除。
- 释放且超过一天的抓取锁可清理；分组任务继续沿用完成后最多一天的保留。修订快照最多保留最近四版、最长七天，并裁剪其中超出十年的内容；异常记录保留三十天。内部租约和任务不重复生成历史修订快照。
- 独立 worker 即使队列为空也执行清理：每分钟最多扫描 200 条主记录，持久记录扫描游标，循环覆盖全库。辅助修订/异常记录每天检查。清理采用 CAS，读取后又更新的记录不会被误删，清理不改变数据的获取时间或有效期。

运行要求：保持 `npm run market:worker` 受进程管理器监管，网页服务和 worker 继续使用现有私有凭证配置，详见根目录 `WORKBUDDY_MARKET_UPDATES.md`。worker 停止时不会承诺空闲库已定时清理；恢复后继续扫描。清理失败记录服务器错误，并保留原数据，不阻断已有更新队列。

## 验证目标

重复跨页面查看、切换财务字段时核对来源调用数；检查十年边界、闰日、股本期初状态、报表列对齐、盘前转开盘缓存、旧租约及清理 CAS。数据库测试使用隔离 PostgreSQL 引擎，生产连接、真实多实例负载和部署时限仍需上线阶段验收。

2026-10-21 本地验收：353 项回归全部通过，生产构建通过。隔离 PostgreSQL 引擎验证逐根行情删除、修订快照截断、CAS 删除和抓取租约。实际浏览器打开自选页无运行错误；贵州茅台两年财务从两项切换为三项指标后，两份已存来源页的获取时间及摘要保持不变，接口耗时由该次首读 650ms 降至 18ms（仅此样本，不代表全站性能保证）。后台日志确认持续扫描并裁剪旧记录；使用独立本地文件目录，不连接生产库，没有推送 Git。
