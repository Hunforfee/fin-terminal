# 证券目录搜索

搜索范围包含仓库已有的 A 股和港股目录，以及原有指数、基金。目录与行情、财报覆盖情况独立。

源服务器使用现有 `getMarketStore()` 对应的持久存储，目录记录键为 `security-directory:v1`，不需要新建数据库表。首次查询时，空库由 `security-directory-seed.json` 初始化；该种子来自现有证券研究目录快照，并用内置简称补充，不代表交易所实时上市名册。目录不声明证券实时上市状态。

每个服务进程加载目录并建立代码、名称、拼音全拼及首字母索引，60 秒内复用；之后重新检查数据库。数据库中的目录是权威来源，更新目录无需部署代码。查询命中直接返回，未命中才调用现有网络联想，成功结果合并入库；并发冲突会重新读取合并。数据源故障不覆盖已有目录，写库失败不阻断已取得的搜索结果。数据库不可用时保留内存目录；进程首次启动则使用基础目录。

当前没有新增交易所全量名册定时同步任务；新证券可由未命中的联网搜索补充，已收录公司的改名和退市状态仍需维护目录，不能把种子当作实时名册。

`MARKET_DATA_MODE=remote` 的消费者继续请求原数据源 `/api/market/data?resource=search`，不在消费者初始化本地目录。因此需要部署实际源服务器，才会启用数据库目录搜索。源服务器必须保留原持久化存储及写入权限；未配置持久化存储时只能使用基础目录和网络结果，不能宣称已落库。

本次不修改行情、财务、选股和补齐逻辑。
